# 桌面端预装能力

[English](guide.md) | 中文

## 变更

桌面端预装工坊和 DSH Market，保留桌宠与 Word、Excel、PowerPoint 和 PDF 工作流程。此前的可选插件及业务写作和分析技能退出桌面端默认目录。

## 迁移

1. 打开侧栏，确认可以进入工坊和 DSH Market。
2. 从工坊或插件管理器安装仍需要的可选插件。使用单位认可的副本导入所需的业务 Skills。
3. 确认安装的插件或导入的 Skill 出现在桌面配置中。
