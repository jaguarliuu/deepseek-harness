# 桌面端预装能力

[English](guide.md) | 中文

## 变更

桌面端预装工坊、Better Sidebar 和上下文洞察，保留桌宠与 Word、Excel、PowerPoint 和 PDF 工作流程。此前的可选插件及业务写作和分析技能退出桌面端默认目录。桌面端首次启动时离线安装工坊，保留已有工坊的版本和设置。工坊可通过内网目录独立升级，激活失败时自动恢复旧版本。

## 迁移

1. 打开侧栏，确认可以进入工坊、Better Sidebar 和上下文洞察。
2. 从工坊或插件管理器安装仍需要的可选插件。使用单位认可的副本导入所需的业务 Skills。
3. 确认安装的插件或导入的 Skill 出现在桌面配置中。
