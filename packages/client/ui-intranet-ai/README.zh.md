# @deepseek-ai/dsh-client-ui-intranet-ai

[English](README.md) | 中文

## 概述

在设置中连接内网信息运维 AI 平台，授权平台账号，生成图片、合成语音、识别图片与 PDF。模型工具通过后台任务注册表提交同一套任务。Host 负责令牌、轮询和结果下载，浏览器仅接收安全的账号状态与有界结果预览。不需要本地推理模型或 Python 运行时。

## 使用本包

Web 应用 bundle 挂载本插件，包含 Desktop 配置，内网平台固定为 `https://25.75.3.1`。打开设置 → 内网 AI 能力，直接授权平台账号，无需输入地址或测试网络。密码不保存，可选的能力参数仅调整图片模型和音色 ID，不更改平台地址。管理员须放行员工电脑出口 IP 或网段，并配置可信 HTTPS 证书。证书错误、请求超时及连接被拒绝分别提示，TLS 校验保持开启。

可在能力页面创建任务，或在会话中交给小 C。图片与语音在远端生成；OCR 默认支持最大 20 MiB 的 PNG/JPEG/WebP/BMP/TIFF/PDF 文件。语音输出为 24 kHz WAV。文本或提示词上限为 2,000 字。支持的图片尺寸、模型和音色 ID 由平台决定，应与实际部署保持一致。

任务展示平台状态、已确认的取消、部分图片失败和 OCR 页数截断。关闭页面不会取消任务。重启应用后保留远端任务 ID，可通过“继续查询 / 下载”恢复，避免重新提交。提交结果未知时应先核对工坊历史记录，再创建新任务。本地等待超时不代表远端取消。

结果存放在当前配置的 `dataPath`，可在设置页预览或保存。OCR 预览会缩短，保存的 Markdown 包含完整响应。本地默认保留最多 500 条记录，达到上限后拒绝新增提交；列表最多显示 30 条，每条 OCR 预览不超过 2,000 字。管理员保留记录管理延后实现。

授权使用现有凭据存储保存平台轮换令牌，按平台根地址隔离。刷新通过凭据记录修改操作串行执行。平台或账号变更后，任务不能使用其他账号的令牌。刷新授权到期后需要重新授权；断开时先清除本地令牌，再请求服务端吊销，网络报错表示远端吊销尚未确认。

### 内网环境验收

真实平台由用户在内网验证，本地模拟接口不能证明生产兼容性。请在内网 Windows 安装环境逐项检查：

1. 确认平台地址已内置并直接授权；如需调整模型与音色 ID，确认重启后参数保留。
2. 授权已准入账号，检查密码错误和 IP 不在白名单时的提示。
3. 分别生成一张和三张图片，预览并保存，核对部分失败是否有提醒。
4. 合成中文语音，播放并保存 WAV，核对音色与语速。
5. 识别图片和 PDF，保存 Markdown，对照源文件检查页数和截断提醒。
6. 等待访问令牌到期后查询任务，验证刷新；刷新授权到期后重新授权，并测试切换账号。
7. 取消排队及运行任务，断网并重启应用，再查询原任务，确认没有重复提交。

<a id="understand-the-implementation"></a>
## 理解实现

`intranetAi` 服务负责账号隔离的 Remote 操作和受 effect 管理的模型工具。`platform.ts` 校验根地址、限制 HTTP 响应大小、拒绝重定向、串行刷新令牌并隐藏上游错误正文。`tasks.ts` 保存第 1 版任务索引和下载结果，在支持的平台使用仅所有者权限。任务存储损坏时拒绝初始化，不静默替换历史记录。

提交时分别解析生图裸响应与 TTS/OCR 成功包裹。轮询解析裸记录，并在平台终态停止。下载必须位于任务绑定的平台同源 `/static/` 路径，HTML 响应不能保存为 WAV。部分失败和下载失败保持可见。请求、轮询、等待、上传、下载、响应和保留限制均由部署 Config 配置。

`tools.ts` 注册 `intranet_image_generate`、`intranet_tts` 和 `intranet_ocr`。OCR 路径通过当前文件系统服务解析和读取。后台任务返回本地文件路径与有界 OCR 预览。取消和完成使用现有 jobs 注册表；退出时中断本地查询并等待写盘结束，无法保证不可达的远端 worker 已停止。

<a id="model-experience"></a>
## 模型体验

### 内网 AI 工具

#### 模型看到的内容

模型看到三个不接收凭据参数的能力工具。创建后返回后台任务 ID，模型必须通过 `job_output` 获取结果，再确认完成。工具调用复用现有通用卡片。完成结果包含保存路径、任务状态和 OCR 截断信息，不包含平台令牌及原始错误正文。现有 Skills 可组合调用这些工具。

#### Token 影响

插件挂载期间包含三个工具定义；OCR 文本仅在获取后台任务结果或明确读取文件后进入模型上下文。

#### KV Cache 影响

刷新账号授权不改变工具列表。每次任务结果会改变会话历史，账号令牌不会进入提示词。

## 已知限制与延后工作

<a id="known-limitations-and-deferred-work"></a>

- 这里尚未验证真实内网平台连通性和输出质量，本地测试仅调用回环 HTTP 模拟服务。请在内网核对平台根地址、IP 白名单、证书信任、账号刷新、实际模型和音色 ID，以及下载的媒体文件。TLS 校验保持开启。

- 图片编辑、蒙版、音色克隆、ASR、实时流、远端历史导入、任务删除和专用会话媒体卡片延后实现。本地缓存与服务端历史分开保存，服务端取消是尽力操作。第一版输出 OCR Markdown，不展示版面框及裁剪图画廊。
