# 秦小智皮肤

[English](README.md) | 中文

面向 DSH 0.2.2-rc.1 的独立皮肤与控制台。使用现有主题、侧栏、欢迎图标和设置接口，安装时无需修改 DSH 源码或重新编译。

## 安装或升级

在 DSH 插件管理中卸载旧版秦小智插件，再添加 `intranet-dsh-skin-qinxiaozhi-0.2.0.tgz` 的绝对路径并启用。如果页面仍显示旧资源，刷新一次即可。这不会删除会话。从本仓库进行本地安装的等效命令是：

```sh
pnpm dsh plugin --profile web add "$PWD/local-plugins/qinxiaozhi-skin"
```

使用 CLI 安装后，在插件管理中启用已安装的包。桌面客户端应通过应用自己的插件管理安装，使插件归属桌面配置。

## 皮肤控制台

侧栏底部提供**皮肤控制台**入口，设置 → 通用中也有**打开皮肤控制台**。关闭皮肤自身的开关后，这两个入口仍然保留；在插件管理中禁用整个插件才会移除它们。

- **启用秦小智皮肤**：切换配色、侧栏 logo 和选定的布局功能。关闭后恢复原主题与品牌。
- **皮肤配色**：选择深色或浅色，默认深色，不受 DSH 原有外观偏好影响。
- **会话列表在上，操作入口在下**：将工作区和会话区域移到操作列表上方，收起态保持原布局。
- **显示秦小智欢迎页**：通过已发布的欢迎图标插槽替换欢迎内容，输入框和工作场景入口保持原有行为。
- **恢复皮肤默认设置**：启用皮肤、深色配色、会话优先排列和欢迎页。

设置经服务端校验后保存到 `qinxiaozhi-skin` 配置命名空间，并应用于使用该配置的浏览器。控件显示已确认的设置，保存期间禁用，保存被拒绝或失败时显示提示。若部署通过主目录补丁或命令行覆盖锁定配置，需要先移除该覆盖，控制台才能保存。刷新后保留已保存的选择。

## 兼容性与素材

皮肤不再使用开发期间新增的 `conversation.hero.content` 插槽或 `data-sidebar-section` 属性。布局样式以现有侧栏和欢迎图标插槽结构为依据；未来 DSH 布局变化时，可能需要更新这些选择器。本插件不复刻参考截图的技能市场或原生窗口标题。

机器人徽标从用户提供的截图提取为透明图并放大，细节依据小尺寸原图重建。包内包含图片和打包后的服务端 schema 库，运行时无需下载字体、图片或脚本。`host-source.js` 是服务端入口源码；打包前在仓库执行 `pnpm exec esbuild local-plugins/qinxiaozhi-skin/host-source.js --bundle --platform=node --format=esm --outfile=local-plugins/qinxiaozhi-skin/index.js` 重新生成 `index.js`。
