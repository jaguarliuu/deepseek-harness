# 运维套件

[English](README.md) | 中文

本文说明面向兼容的 0.2.2 候选版本 Web Host 的离线合并包。一次安装同时启用远程运维和运维大屏，并包含两者的运行时依赖。Cordis 及应用已有的凭据、审批、工具、存储和 Web 服务由 Host 提供。包内不含凭据或采集数据。

将 ZIP 作为一个插件组合导入。打开运维大屏 → 管理 SSH 服务器，配置地址、端口、用户名和认证方式，核验主机指纹后保存。返回监控管理 → 接入监控，选择服务器和脚本。接入确认后才开始采集。本包使用标准 `dsh.bundle.patch` 机制；仅加载浏览器资源的导入器无法启用后端服务。本仓库不包含内网专用 ZIP 导入器。

配置补丁停用独立的 `ui-remote-ops` 和 `ui-ops-monitor` 行，再各启用一个套件实例。独立行不存在时可能出现不影响加载的补丁目标提示。自定义行 ID 需要管理员协调。凭据和监控存储名称保持一致，套件不会删除数据。停用套件不会自动重新启用已单独停用的插件组合。

执行 `pnpm run build:artifacts` 后，运行 `python3 local-plugins/ops-suite/package.py`。脚本解析两项功能的运行时依赖，打包工作区构建产物，携带第三方 JavaScript 依赖及许可证，向 `output/ops-suite` 输出 ZIP 和 npm 压缩包。不包含可选的 SSH 平台原生加速模块，SSH 使用可移植实现。对等依赖由兼容 Host 提供。压缩包内均为普通文件，不含符号链接或工作区版本引用。
